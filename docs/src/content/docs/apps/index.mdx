Every app is deployed from the repository by Flux. Some also need steps taken by hand: an account created in a UI, an OIDC client registered in Pocket ID, a setting that lives in the app's own database. These pages hold those steps, one page per app that has them.

- Sign-in and identity: [Pocket ID](/apps/pocket-id/), the passkey provider every other sign-in rests on.
- Cluster tools: [Radar](/apps/radar/), [Hubble](/apps/hubble/), [PegaProx](/apps/pegaprox/), [Network Optimizer](/apps/network-optimizer/), [UniFi DNS](/apps/unifi-dns/).
- Storage: [RustFS](/apps/rustfs/), the in-cluster S3 store that apps keep files in.
- Observability: [Grafana plugins](/apps/grafana-plugins/), which also covers Grafana's own Pocket ID sign-in.
- Household apps: [Actual Budget](/apps/actual-budget/), [Reactive Resume](/apps/reactive-resume/), [Kener](/apps/kener/), the [media stack](/apps/media/) and [Maintainerr](/apps/maintainerr/).
- AI: [LocalAI](/apps/localai/) on the GPU node and [AI Workspace](/apps/ai-workspace/) and [AI KB](/apps/ai-kb/).
- The public site: [matherlynet](/apps/matherlynet/).

Apps with no page need nothing by hand once Flux has deployed them.
