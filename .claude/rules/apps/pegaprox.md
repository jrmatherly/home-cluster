# PegaProx (`[pegaprox]`)

- `[pegaprox]` in `cluster.toml` (one database key, needing nothing else) gates the `pegaprox` namespace, which enforces the `restricted` pod security level. `pegaprox/pegaprox` is PegaProx, a web UI for Proxmox, on the app-template chart at `pegaprox.${SECRET_DOMAIN}` on the internal gateway only. It stores the Proxmox credentials and an API token with privilege separation off in its SQLite database on a 1Gi `local-path` volume at `/app/config`, so the Deployment uses `Recreate` and the volume is the only copy. The pod runs as uid 999, because the image's user is a name that `restricted` cannot check. Behind a proxy the UI dials the console WebSockets on its own origin, but separate servers answer them, so the HTTPRoute sends `.../vncwebsocket` to 5001 and `.../shellws` to 5002 and everything else to 5000; the syslog receiver on 1514, on by default, is not exposed and should be turned off in its settings. PegaProx has no plugin installer: a plugin is a directory under its plugins path, which since 1.4.0 is `/app/config/plugins` on the config volume; the app syncs the image's bundled plugins into it on every start, replacing their files but keeping each plugin's `config.json`, so a new plugin is copied there and picked up with Rescan (until 1.4.0 that path was a second volume; dropping it on 2026-10-24 renamed the app-template claim, and Helm and local-path deleted the database, restored 2026-10-31 from `private/backups/`). The first visitor to a new instance creates the admin account, so the route stays internal. Single sign-on with Pocket ID is set up in its UI and stored in its database, not in this repo; the gitignored `private/pegaprox-setup.md` lists those steps. Its OIDC redirect URI is `/oidc/callback`, and a local admin must not share a Pocket ID username, because an OIDC login never adopts a local account of the same name. Never change `db_key`: it encrypts the database, which becomes unreadable. The optional `metrics_token` (an API token with the admin role, needing `[observability]`; the endpoint rejects any other role) adds the Prometheus scrape of `/api/metrics` and the upstream "PegaProx Cluster Overview" dashboard, following the metrics conventions in `.claude/rules/flux-apps.md`. The `public` fixture sets the section and the token.
